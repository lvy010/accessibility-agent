## 本次修复

- 移除打包的 `--no-dependencies`，避免 Playwright 在资源白名单处理前被排除；验证运行时必须从解包目录解析，而不是开发目录。
- 保留 axe-core、zod 与 Playwright 的第三方许可；检查包内资源及排除开发数据。
- 模型提供方不响应取消时，插件停止等待；覆盖 token 计数、请求与流读取边界，拒绝不合法输出。
- 支持明确确认的工作区级验证任务，仍排除全局任务、其他文件夹任务和后台任务。
- 宿主测试使用启动器传入的真实 Node 路径，避免将 Code.exe 当作 Node 启动。测试必须产生完成标记，不能只看进程退出码。
- CI 补齐 Windows 稳定版检查，并在上传构件前执行包内验证。
